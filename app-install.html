홈 화면에 추가하는 방법

사용하시는 기기를 골라 주세요

  1. 1크롬 또는 삼성 인터넷에서 앱 열기

    위의 앱 열기 버튼을 누르거나 QR코드를 찍어 주문 앱을 열어요.

  2. 2메뉴 누르기

    크롬은 오른쪽 위 ⋮, 삼성 인터넷은 오른쪽 아래 ≡ 를 눌러요.

  3. 3홈 화면에 추가

    앱 설치 또는 홈 화면에 추가 를 누르면 바탕화면에 뉴키즈 아이콘이 생겨요.

화면 아래에 “앱 설치” 안내가 바로 뜨면 그 버튼을 눌러도 돼요.
  1. 1사파리(Safari)에서 앱 열기

    위의 앱 열기 버튼을 누르거나 카메라로 QR코드를 찍어 사파리로 열어요.

  2. 2공유 버튼 누르기

    화면 아래(또는 위) 가운데의 □↑ 공유 버튼을 눌러요.

  3. 3홈 화면에 추가

    목록을 내려 홈 화면에 추가 를 누르고, 오른쪽 위 추가 를 누르면 끝!

아이폰은 카카오톡·네이버 앱 안에서 열면 홈 화면 추가가 안 보여요. 꼭 사파리에서 열어 주세요.
  1. 1크롬 또는 엣지에서 앱 열기

    위의 앱 열기 버튼을 눌러 주문 앱을 열어요.

  2. 2설치 아이콘 누르기

    주소창 오른쪽 끝의 설치(모니터 모양) 아이콘을 눌러요.

  3. 3설치

    설치 를 누르면 바탕화면과 시작 메뉴에 뉴키즈 주문이 생겨요.

아이콘이 안 보이면 오른쪽 위 메뉴 ⋮ → 전송, 저장 및 공유 → 페이지를 앱으로 설치 를 눌러 주세요.
